# DAX Measure Library

| File | Purpose |
|------|---------|
| `01_Core_Measures.dax` | Core KPIs: patient/stroke counts, stroke rate, relative risk vs baseline, contribution %, high-risk metrics |
| `02_Formatting_Measures.dax` | `Bar Color` measure for coral/teal conditional formatting on charts |

Measures live on the `_Measures` table in the Power BI model.
